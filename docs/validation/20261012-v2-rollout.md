# v2 落地验证（2026-10-12）

## 范围

cms-parquet-v2（KyStd 兼容）格式落地：归档器升级、v1→v2 转换器、cms_rtf v2 直读、
parquet→journal 回放框架。设计：[../../cms_market_gateway/docs/design-parquet-v2.md]。

## 结果

1. **格式透明性（因子口径）**：同一 CMS 数据，v2 读出的因子与 v1 读出的
   **106/106 列逐位一致**；与华泰参考（HT 数据源）维持 104/106 列 corr>0.99
   （与 v1 路径完全相同的水平）。
2. **v1→v2 转换器**：20261009 全天转换 535,706,255 行（与 v1 行数一致），
   order 19 片 + trade 15 片；SZ 撤单 57,280,779 行从 order 迁入 trade
   （SZ_order 219,409,412→162,128,633、SZ_trade 90,969,354→148,250,133，总量守恒）。
3. **回放框架 roundtrip**：合成数据（SH A/D/T、SZ 限价/市价/U、SZ 成交/撤单、
   同报文多事件、双市场混排）经 v2 parquet → EFH 重建 → 确定性 UDP 回放 →
   网关 → journal → 重归档 v2，与源逐字段一致（`tests/replay_roundtrip.py` PASS）。
4. **线上部署**：cms-archive-0.2.4（含 v2 归档器 + 回放/转换工具）经 git bundle
   上线，远端自测通过；次日起 15:35 cron 直接产 v2。

## 过程缺陷记录

- codec_v2 初版把 `Price` 写进不存在的事件字段 `price_tick`（正确名 `px_tick`），
  210M 行价格变 0 —— 由 v1/v2 事件流逐字段 diff 抓出；单测已补 px_tick 断言。
- 同文件 `Time`（HHMMSSmmm）未换算成午夜毫秒，内核判定全部在盘外 ——
  由空 book/flow 输出暴露；单测已补单位断言。
- pyarrow 11 无 `write_page_checksum`/`page_checksum_verification`（线上 23 有），
  归档器加了版本门。
